# Stopwatch 4 TS

Stopwatch 4 TS is a time-study app for recording, evaluating, and documenting cycle times on iPhone and iPad.

## Availability

Available on the App Store for iPhone and iPad.

## Features

### Time recording

- Display times in either 1/100 minutes or minutes and seconds.
- Record cycle times manually or use automatic triggering.
- Trigger measurements using the accelerometer to detect movement or vibration.
- Trigger measurements using the camera by comparing a reference image with the current image.
- Set the number of parts produced per cycle.
- Add, deactivate, reactivate, or delete individual measurements.
- Add notes and predefined reasons for interruptions to individual measurements.

### Statistics and analysis

- Calculate parts per hour, including an optional OEE target.
- Display average, dispersion, minimum, maximum, accuracy (epsilon), and standard deviation.
- Show the total number of measurements and the estimated number still required to reach the configured epsilon target.
- Highlight minimum and maximum values using configurable colors.
- Include or exclude deactivated measurements in charts and evaluations.

### Managing time studies

- Rename and delete recordings.
- Sort recordings by name or date.
- Import and export time studies in the `.sft` file format using the iOS Share Sheet.
- Export measurement data as CSV with configurable separators and decimal formatting.
- Create and restore complete ZIP backups containing multiple recordings.

### Reports and sharing

- View detailed statistics and measurement charts.
- Generate and share a complete time-study report as a PDF.

### Legacy iCloud access

- Access and download existing recordings from iCloud.
- Uploading new recordings to iCloud and sharing recordings through sharing keys are no longer supported.
- The remaining read-only iCloud access is scheduled to be discontinued at the end of 2026.

### iPad and Process Flow

- Use the regular stopwatch and all standard time-study functions on iPad.
- Work with an iPad-optimized split-view layout.
- Optionally create and perform Process Flow studies on supported iPads.
- Import Process Flow packages generated by the companion Stopwatch 4 TS web app.

### Appearance

- Switch between light and dark mode throughout the app.
